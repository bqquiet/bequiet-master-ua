## 📂 Pages

* **`/` (Home)** — Bio, tech stack overview, and GitHub repository explorer.
* **`/news` (News)** — Articles, GitHub activity, and tag filters.
* **`/about` (About)** — Skills and professional timeline.
* **`/contact` (Contact)** — Links and contact form.
* **`/admin` (Admin)** — Protected panel for content management.

---

## 🚀 How to Run Locally

Clone the repository, open your terminal in the project folder, and run:

```bash
# Install dependencies
npm install

# Start the server
npm start

``` 

The app will open at [http://localhost:3000](http://localhost:3000)
